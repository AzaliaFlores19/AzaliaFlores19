# Hi, I'm Azalia 👋

Full-stack developer from San Pedro Sula, Honduras. I'm finishing my Computer Systems Engineering degree at UNITEC (graduating 2027), and lately I've been spending most of my time on the DevOps side with Docker, GitHub Actions, deployments.

## Featured work

### 🧾 Koara Billing & Administration System
University outreach project. A centralized billing, POS, and inventory system.
I led the team of 4 as **Scrum Master** and built the front-end in
**Next.js 16 + React 19 + TypeScript + Tailwind CSS 4**, alongside a **NestJS** backend for sales,
billing, and real-time inventory, with Cloudflare R2 storage, JWT auth, and SAR e-invoicing compliance.

`Next.js` `NestJS` `TypeScript` `PostgreSQL` `Cloudflare R2` `RBAC`

[Frontend](https://github.com/AzaliaFlores19/koara_frontend) · [Backend](https://github.com/AzaliaFlores19/Koara_backend)

---

### ⛪ Seminario Menor Santiago Apóstol Frappe/ERP System
Real client project with a team of three. A custom **Frappe** app that manages seminarians,
documents, assets, staff, and finances.

My part: domain doctypes and business logic in **Python**, the finance and asset reports and
dashboards, and collaborating on the project's CI/CD built with **GitHub Actions**.

`Frappe` `Python` `Docker` `GitHub Actions` `MariaDB` `Redis`


---

### ☀️ MIDAS Solar Proposal Generator
Real client project built with a teammate for **Corporación Midas**. A Frappe app that turns a
quotation into a technical and financial EPC solar proposal, exported to PDF and Word with charts —
containerized and shipped with a full CI/CD pipeline.

The pipeline automatically builds a Docker image (frappe_docker base + a WeasyPrint layer), pushes
it to Docker Hub, and deploys via a **Portainer webhook** triggered from **GitHub Actions** on each
push.

`Frappe` `Python` `Docker` `Docker Compose` `GitHub Actions` `Docker Hub` `Portainer`

[Repository](https://github.com/dcruzparedes/midas_app)

---

### 🎬 Bora Log Series Tracker
Personal project (in progress). Log the series you watch, rate them, leave comments, and add your
own custom classifications, using the **TMDB API**. Built with **Prisma + PostgreSQL**, JWT
authentication, and email notifications; adding a CI/CD pipeline.

`Next.js` `Prisma` `PostgreSQL` `JWT` `TMDB API` `CI/CD`
